# 🎵 Spotify Clone — Frontend

A responsive **Spotify-inspired music streaming UI** built from scratch using **HTML5 and CSS3**, with **Font Awesome** used for icons.

This project focuses on recreating the visual structure and layout of Spotify while practicing modern frontend development concepts such as **Flexbox, CSS Grid, responsive design, positioning, spacing, and reusable UI components**.

> ⚠️ This is a frontend practice project and is **not affiliated with or endorsed by Spotify**.

---

## 📌 Project Overview

The goal of this project is to build a Spotify-inspired interface using only frontend technologies.

The project focuses on:

* 🎨 Clean and modern UI design
* 📱 Responsive layouts
* 🧱 CSS Flexbox and Grid
* 🎵 Music-player interface
* 📚 Sidebar navigation
* 🎧 Playlist and album cards
* 🔍 Search interface
* 🎚️ Player controls
* ✨ Font Awesome icons

## ✨ Features

### 🏠 Home Page

* Spotify-inspired homepage
* Navigation sidebar
* Recently played section
* Recommended music
* Popular artists
* Album/playlist cards

### 📚 Sidebar

Includes navigation such as:

* Home
* Search
* Your Library
* Playlists
* Liked Songs

### 🎵 Music Cards

Each music card contains:

* Album artwork
* Song/playlist title
* Artist or description
* Hover effects

### 🎧 Music Player

Spotify-inspired bottom player containing:

* Album information
* Previous button
* Play/pause button
* Next button
* Progress bar
* Volume control
* Additional player controls

> The player is currently a **UI-only component** and does not actually play music.

### 📱 Responsive Design

The layout is designed to adapt to different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to modify the layout for smaller screens.

## 🔗 Font Awesome

Font Awesome is used for the icons in the interface.

Example:

```html
<i class="fa-solid fa-house"></i>
<i class="fa-solid fa-magnifying-glass"></i>
<i class="fa-solid fa-book"></i>
<i class="fa-solid fa-play"></i>
<i class="fa-solid fa-forward"></i>
```

Font Awesome can be included using its CDN:

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css"
>
```
