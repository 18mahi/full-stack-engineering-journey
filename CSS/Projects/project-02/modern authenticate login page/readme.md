# 🔐 Modern Login & Authentication UI

A responsive and professional **Login & Authentication UI** built from scratch using **HTML5 and CSS3**.

This project is part of my frontend development learning journey and is designed not only to create a visually appealing interface, but also to strengthen my understanding of **HTML structure, CSS layouts, responsive design, form styling, accessibility, and modern UI techniques**.

> **Note:** This is a frontend-only authentication interface. No real authentication or backend functionality is implemented.

---

## 📌 Project Overview

The goal of this project is to build a realistic authentication interface similar to what users may encounter in modern web applications.

Instead of creating only a simple login form, this project includes multiple authentication-related pages and focuses on writing the interface **from scratch using only HTML and CSS**.

The project covers:

* Login
* Sign Up
* Forgot Password
* Reset Password
* Responsive layouts
* Form states
* Interactive UI elements
* Accessibility
* Modern CSS techniques

## 📱 Responsive Design

The interface is designed to work across different screen sizes:

```text
💻 Desktop
    ↓
📱 Tablet
    ↓
📱 Mobile
```

The layout adapts according to the available screen width using CSS media queries.

The objective is to ensure that:

* Forms remain readable
* Buttons remain accessible
* Content does not overflow
* Spacing adapts to smaller screens
* Authentication cards remain usable on mobile devices

## 💡 Project Philosophy

This project is intentionally built **without Bootstrap, Tailwind CSS, or any other CSS framework**.

The purpose is to understand what happens behind the components that frameworks normally provide.

Instead of simply using:

```text
Framework → Component → Done
```

I want to understand:

```text
HTML
  ↓
CSS
  ↓
Layout
  ↓
Responsive Design
  ↓
Interaction
  ↓
Accessibility
  ↓
Professional UI
```

This approach helps me build a stronger foundation before moving toward larger frontend frameworks.
