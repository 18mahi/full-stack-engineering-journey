# 🟢 Basic Navbar Challenge

## 📌 Objective

Create a basic navigation bar using **HTML5 and CSS3**.

The goal is to practice:

* HTML semantic elements
* Lists and links
* CSS Flexbox
* Spacing and alignment
* Hover effects
* Basic button styling

---

## 🧩 Requirements

### HTML

Create a navbar containing:

* **Website name:** `CodeSpace`
* **Navigation links:**

  * Home
  * About
  * Services
  * Contact
* **Button:** `Login`

Use:

* `<nav>` for the navbar
* `<ul>` and `<li>` for navigation links
* `<a>` for links
* A suitable element for the Login button

---

## 🎨 CSS Requirements

Style the navbar so that:

1. It has a **dark background**.
2. Text is **white**.
3. The navbar has appropriate **padding**.
4. Navigation links appear **horizontally**.
5. Default `<ul>` bullets are removed.
6. There is spacing between navigation links.
7. Default link underlines are removed.
8. The Login button has a different background color.
9. Navigation links change color when hovered.
10. **Flexbox** is used to arrange the navbar elements.

## 🚫 Rules

* Write the HTML yourself.
* Write the CSS yourself.
* Do not use Bootstrap, Tailwind, or other CSS frameworks.
* Do not use JavaScript.
* Do not worry about responsive design for this challenge.

---

## ⭐ Bonus Challenges

After completing the basic navbar, try adding:

* A hover effect to the Login button.
* A border-radius to the Login button.
* A different font size for `CodeSpace`.
* An `active` style for the Home link.
* A subtle box shadow on the navbar.
